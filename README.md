# TableTime

Учебное Full Stack приложение для бронирования столиков в ресторане.

## Стек

- React, TypeScript, Vite
- Java, Spring Boot, Spring Data JPA
- PostgreSQL, Docker Compose

## Локальный запуск

1. Запустить базу: `docker compose up -d`.
2. Запустить backend из папки `backend`.
3. Выполнить `npm install` и `npm run dev` в папке `frontend`.
